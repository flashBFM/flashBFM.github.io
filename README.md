# FlashBFM Official Website

This repository hosts the static website served at:

<https://flashbfm.github.io/>

## Structure

```text
index.html    # Main one-page site
styles.css    # Design system and responsive layout
script.js     # Navigation and reveal effects
favicon.svg   # Brand favicon
```

## Update the site

Edit the content in `index.html`, adjust styles in `styles.css`, commit your changes, and push to `main`. GitHub Pages publishes automatically.
